Проект "Tower Jump" — аркадная мобильная игра в духе Helix Jump и Stack Ball
Это мобильная аркадная игра для платформы Android, созданная по мотивам популярных тайм-киллеров, таких как Helix Jump и Stack Ball. Игрок управляет мячом, который прыгает вниз по вращающейся башне, разрушая платформы и стараясь избежать опасных зон.

Ключевая цель игрока — спуститься как можно ниже, разбивая платформы и избегая ловушек. Управление осуществляется с помощью свайпов по экрану, вращая башню вокруг своей оси, чтобы выбрать безопасный путь.

Основные особенности проекта:
- Простое и интуитивное управление свайпами
- Динамичный и затягивающий геймплей
- Разрушаемые платформы и препятствия
- Поддержка мобильных устройств на Android

Проект Tower Jump был создан на раннем этапе моего обучения разработке игр. Он стал для меня важным опытом освоения игровых механик, логики столкновений, а также адаптации под мобильные платформы.
